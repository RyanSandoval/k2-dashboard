## 2024-05-19 - Added labels to New Smart List inputs
**Learning:** Found several input elements inside of modals that were using `<label>` elements visually but missing the `for` attribute that links them to the `<input>` or `<select>` elements.
**Action:** Always verify if modal forms correctly link their `<label>` and `<input>`/`<select>` elements with matching `for` and `id` tags.
